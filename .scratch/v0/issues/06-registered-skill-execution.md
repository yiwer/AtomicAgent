# 06 — 登记 Skill 并证明任务实际使用

**What to build:** 维护者登记一个固定 Skill，调用方选择它完成文件任务，A 展示所请求、装载、可调用及实际使用的不同证据。

**Blocked by:** 02 — 上传文件并交付可下载的处理结果；05 — 发布环境与模型修订并用于新任务

**Status:** ready-for-agent

**Implementation:** implemented and locally verified/reviewed; real integration and human acceptance pending.

**范围来源：** PRD + A；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** AC-03、AC-08、AC-27。

**管理台验收对应：** A-AC-02。

## Acceptance criteria

- [ ] 请求可组合获准的固定 Skill 修订，内容／入口固定且不继承宿主或前次会话；参数不能扩大授权。
- [ ] 必需 Skill 初始化／加载失败明确失败；复制文件不等于引擎可调用。任务声明必须使用时需受控调用或等价可核对使用证据。
- [ ] Skill 修订／停用沿用配置语义；任务仍通过普通文件交付和清理路径，不新增整项重跑或模拟成功入口。

## 验证与证据

真实 Claude 加载并使用登记 Skill 的文件样例；缺入口、加载失败、声明使用但无证据的反例。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
