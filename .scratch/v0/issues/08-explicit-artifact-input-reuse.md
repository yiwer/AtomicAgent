# 08 — 以前次产物显式创建新任务

**What to build:** 调用方显式选择仍有效的前次 Artifact 作为新 Run 输入，在详情核对输入来源和独立副本，完成新的文件任务。

**Blocked by:** 02 — 上传文件并交付可下载的处理结果

**Status:** ready-for-agent

**范围来源：** PRD + A；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** AC-04。

**管理台验收对应：** A-AC-01。

## Acceptance criteria

- [ ] 在最早可判断阶段校验归属、授权、未过期、完整内容及安全目标路径；装载时再次核对，不接受同名替换。
- [ ] 新 Run 获得自身 InputBinding 和输入副本，不继承旧会话、进程或权限；原产物到期不延长，新副本由新 Run 清理。
- [ ] 任一任务结束不能删除另一个仍合法使用的共享源材料；复制失败／源过期明确失败，原 Run 的 Result 和幂等身份不变。

## 验证与证据

两次真实任务配合受控时间／复制故障；核对原产物 TTL、新副本和共享材料生存期。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
