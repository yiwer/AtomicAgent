# 28 — 保存固定能力组合并用于提交任务

**What to build:** 维护者把登记环境、模型、Skills 和可选 MCP 固定为可复用组合，调用方或 A 提交入口选择组合完成普通 Run。

**Blocked by:** 06 — 登记 Skill 并证明任务实际使用；07 — 通过登记只读 MCP 交付研究报告

**Status:** ready-for-agent

**范围来源：** A 新增；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** 原型 A 的已批准管理行为；完整页面及来源责任见票务计划。

**管理台验收对应：** A-AC-09。

## Acceptance criteria

- [ ] 组合固定确切修订及摘要，只是提交配置的复用方式，不成为新的执行或授权主体；至少支持文件和研究两类组合。
- [ ] 提交时按实际调用身份重新核验所有配置／参数和有效授权；停用或失效成员明确拒绝，不改选 latest。
- [ ] 保存／选择／更新组合产生可追溯修订，已有 Run 清单不漂移；不得通过组合或管理台任填调用方身份扩大权限。

## 验证与证据

两个组合分别完成真实文件／研究任务；成员停用、越权及历史修订对照。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
