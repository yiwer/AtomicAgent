# 02 — 上传文件并交付可下载的处理结果

**What to build:** 上传 CSV／JSON，绑定任务内输入位置，实际执行代码生成统计和必需文件；在 A 的任务详情读取 Result 并在 sandbox 清理后下载 Artifact。

**Blocked by:** 01 — 提交提示词并在 A 中取回已校验 JSON

**Status:** ready-for-agent

**范围来源：** PRD + A；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** AC-01、AC-04、AC-08、AC-09、AC-23。

**管理台验收对应：** A-AC-01。

## Acceptance criteria

- [ ] InputObject 校验完成后才可引用；记录 InputBinding、内容摘要和归属。拒绝越权、过期、不完整输入、重复目标、路径／符号链接越界及超额文件。
- [ ] CSV 八行样例：有效 7、拒绝 1 且为 r04，总和 50，alpha 22.5、beta 27.5；有效 CSV 保序、拒绝 JSON 内容正确。增加等价 JSON 输入路径，证明实际读取／代码执行／写文件。
- [ ] schema、必需文件及内容断言通过并转存后，ValidationReport、Result 和产物清单原子提交；缺 JSON、缺文件或伪造完成失败。转存残留始终有归属及回收责任。
- [ ] 下载按身份授权，链接寿命不超过文件剩余寿命；链接签发和可观察传输分开留痕，清理不破坏已交付文件。

## 验证与证据

真实文件任务、独立十进制统计和下载字节核验；在输入、验证器和存储边界注入负例。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
