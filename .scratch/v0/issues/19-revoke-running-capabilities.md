# 19 — 显式撤销运行中授权并核验停止

**What to build:** 维护者从配置影响面板选择需要撤销的运行中授权，审阅影响后提交受控撤销，查看真正停止及回收进展。

**Blocked by:** 06 — 登记 Skill 并证明任务实际使用；07 — 通过登记只读 MCP 交付研究报告；09 — 取消任务并核验实际停止

**Status:** ready-for-agent

**范围来源：** PRD + A；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** AC-18。

**管理台验收对应：** A-AC-02。

## Acceptance criteria

- [ ] 显示精确修订、受影响 Run 和撤销范围；仅有停用操作时不修改旧清单、不停止既有执行。
- [ ] 显式撤销 CapabilityGrant 后阻断新增受控能力并请求停止；终态、实际停止、清理分别记录，不只隐藏按钮。
- [ ] 权限、命令幂等和审计保留；重复撤销安全，取消／成功竞争保持唯一终态，旧运行清单仍可追溯。

## 验证与证据

真实长任务中撤销环境／Skill／MCP 所关联授权，验证后续调用被拒及执行终止。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
