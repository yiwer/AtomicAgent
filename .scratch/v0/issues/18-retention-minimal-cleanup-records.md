# 18 — 文件到期失效并保留最小未完成回收责任

**What to build:** 文件到期后不能再下载，记录窗口内仍能查看 JSON／清单；常规数据删除后维护者仍可定位孤儿资源，完成处置后再删除最小记录。

**Blocked by:** 08 — 以前次产物显式创建新任务；16 — 上传或提交中断后恢复交付而不重跑；17 — 从回收单重试处置并核验资源消失

**Status:** ready-for-agent

**范围来源：** PRD + A；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** AC-17。

**管理台验收对应：** A-AC-01。

## Acceptance criteria

- [ ] 产物从终态提交起 24 小时失效；所有链接／代理／直接下载路径拒绝过期访问。链接提前过期但文件尚存时可重新授权，不能延长文件 TTL。
- [ ] Run、Result、清单、事件、幂等及对应审计从终态后 7 天删除；无 Run 记录从记录时起 7 天，活跃执行依据不提前删除。未使用上传 24 小时，失败上传／未提交残留纳入清理。
- [ ] 常规保留不超过规定期限；未回收例外只留不透明资源定位、责任类型及下一处置时间，不留正文／secret／Result。核验回收后 7 天删除最小记录。
- [ ] 访问失效与物理删除分别取证；展示到期／删除／暂存及最小例外积压，不因过期或回收异常重跑业务。

## 验证与证据

受控时钟跨 24 小时／7 天／闭合后 7 天，实际检查所有访问途径、对象删除和记录最小化。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
