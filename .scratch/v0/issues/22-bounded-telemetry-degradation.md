# 22 — 外部遥测故障时继续任务并展示有界退化

**What to build:** 外部审计导出、指标或 trace 不可用时，任务按内部事实继续，A 显示观测延迟、积压及丢弃，恢复后去重补投。

**Blocked by:** 20 — 按独立审计权限查询和导出操作责任

**Status:** ready-for-agent

**范围来源：** PRD + A；2026-09-14 用户接受 v0＋A 拆分后发布。

**验收对应：** AC-20。

**管理台验收对应：** A-AC-04。

## Acceptance criteria

- [ ] 关键审计独立于 SSE 和 trace 采样；关闭 trace 或导出仍可查询必要操作事实。
- [ ] 缓冲、容量、保留与重试有界；最老积压、丢弃及恢复进度可见，不修改已提交终态或重新执行任务。
- [ ] 外部导出和核心记录故障明确区分；出口字段允许清单及长度限制实际应用，恢复后不重复计量或掩盖缺失。

## 验证与证据

切断受控遥测接收端并填满缓冲，继续真实小任务；恢复后比对去重结果及内部审计。

每票交付可运行命令、最短演示步骤和输入／动作／可观察结果／证据出处。分别记录确定性实验、真实集成及本票适用的浏览器／部署／内容验收；所有验收当前未执行。

## 贯穿本票的边界

- 随本票行为交付权限、关键事实持久化、失败与重复请求处理、所属审计事件及带新鲜度的健康／异常来源。观测出口使用有界字段允许清单。
- 一个 Run 至多一次实际 Agent 执行和一个权威终态；Result、Artifact 可用性和实际回收独立。未知结果先对账，业务重做须新 Run，阶段重试不重置累计限制。
- 页面与 API 查询同一事实；管理操作由服务端授权。提供刷新、越权和错误恢复证据，不以模拟控件或替身结果代替真实路径。
